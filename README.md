# 김서환 포트폴리오

데이터 분석, AI 모델 개선, Agent 기반 업무 자동화와 서비스 개발 경험을 정리한 포트폴리오입니다.

## 주요 경험

- Dacon: 물류창고 출고 지연 예측
- ClarifyTrial: 임상시험 추천 Multi-Agent 시스템
- MedInTech: 병변 탐지 모델 개선 및 배포 검증
- Automail: 프로모션 제안 업무 자동화
- Databrain: 광고 성과 대시보드와 LLM 요약 기능 개발

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## 구성

- `index.html`: 포트폴리오 본문
- `styles.css`: 레이아웃 및 스타일
- `assets/`: 프로필 사진과 아이콘
