배경

구현

  • 초기 증강과 하이퍼파라미터 튜닝에서 F2-score가 5~7% 감소하고 예측 수가 약 25% 감소했습니다. 추론 결과를 정량화하는 분석 코드를 구현해 실패 원인을 파악하고, 모델 구조와 데이터 구성으로 개선 범위를 넓혔습니다.

  • 모델을 ONNX로 변환한 뒤 RTX 5060에서 TensorRT 엔진을 생성했습니다. FP32 45FPS, BF16 55FPS로 입력 영상 30FPS를 상회하는 것을 확인하고, 정밀도를 유지하는 FP32를 선정했습니다.
